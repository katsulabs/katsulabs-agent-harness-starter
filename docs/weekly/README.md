# 주간 보고 표준 (v1.4)

저장소마다 `scripts/weekly/`의 월요일 자동 보고가 같은 모양의 문서를 만들도록 하는 규칙.

| 파일 | 역할 |
|------|------|
| `report-base.md` | 모든 저장소 공통 규칙(산출물·섹션·금지·③④·스크린샷·문체). 프롬프트에 그대로 포함된다 |
| `template.html` | 뼈대와 CSS. `{{REPO}}`만 저장소 이름으로 바꿔 쓴다 |

## 저장소가 정하는 것 (`prompts/report.md`의 "저장소 설정")
- 변경 단위: 티켓(`--merges`에서 TB 번호) 또는 커밋(`--no-merges`를 기능 단위로 묶음). 상세 표 첫 열은 추적 ID(티켓 번호 또는 해시).
- 자료 수집 명령, 기준 ref
- 저장소별 금지 구역(운영 컨테이너 이름, 데이터 폴더, 포트)
- ③ 저장소별 점검(디스크·백업·배포 차이 확인 명령)
- ④ 대상 기술과 우리 버전을 읽는 파일
- 스크린샷 도구와 격리 스택 포트

## 적용 방법
1. `report-base.md`를 저장소의 `scripts/weekly/prompts/report-base.md`로 복사한다.
2. 저장소 `prompts/report.md` 끝에 `{{INCLUDE report-base.md}}` 한 줄을 둔다. `lib.sh`의 `render`가 치환한다.
3. `template.html`을 `scripts/weekly/template.html`로 복사하고 `{{REPO}}`를 바꾼다.
4. 표준을 고칠 때는 이 폴더를 먼저 고치고 버전을 올린 뒤 각 저장소에 다시 복사한다.
