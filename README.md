## 시작

**PowerShell 7.4+** (`pwsh`) — Windows 권장 · macOS도 사용 가능:

```powershell
pwsh scripts/validate-harness.ps1
pwsh scripts/install-githooks.ps1
```

**macOS / Linux / Git Bash**:

```bash
./scripts/validate-harness.sh
./scripts/install-githooks.sh
```
